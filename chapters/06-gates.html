PART 2 · CHAPTER 06

人工闸门与常见坑

痛点钩子：有人追求「一句话进去、成片出来」的全自动流水线。现状是——完全无人值守只能出「能看」的视频，出不了「自己满意」的视频。差别就在闸门上。但闸门设太多，又会把 agent 拖垮：每次停顿都重置上下文。

6.1闸门设在哪：一条权衡曲线

原则只有一句：闸门设在「下游返工成本 > 一次评审时间」的地方。口播栏定稿要设闸门——口播一改，画面、配音、字幕、时长全废；而单条 MG 镜头的配色微调，就不值得停下整条流水线。

但闸门有代价：每次停顿都要打断 agent、重置上下文。所以存在一个最优点——太少返工爆炸，太多停顿拖垮。亲手拖出来看：

闸门数量 · 总成本 U 形曲线
拖动「人工闸门数」：绿线（返工期望成本）下降，琥珀线（停顿+上下文重置成本）上升，白线（总成本）呈 U 形。注意阴影区——推荐的 G1–G4 四个必设闸门，正落在谷底附近。
返工成本：— 停顿成本：— 总成本：—
∑ 想深一层 曲线只是示意（单位是「相对成本」），但形状是真实的：返工成本随闸门指数下降（越早拦截越便宜），停顿成本随闸门超线性上升（上下文重置有固定开销——agent 每次被叫停都要重新装载脚本、素材清单、做到哪一步）。最优解几乎从不在端点——「全自动」和「步步确认」一样贵。

6.2G1–G4：四个硬闸门逐闸讲

闸门设在哪审什么为什么在这
G1定位（选题 / 钩子 / 受众 / 时长）这个选题值不值得做？钩子能不能留住人前 15 秒？10 分钟确认，省掉整条视频白做——越上游的错越贵
G2口播栏定稿按「读出来顺不顺」逐段审口播，不是「看起来对不对」口播一改，画面、配音、字幕、时长全废——下游返工成本最高的点，所以先锁这一栏
G3画面栏草图（口播锁定后）在同一份脚本里补逐镜画面＋素材来源，几分钟铺线框看结构口播已锁定，补画面不再动叙事；一眼看出哪镜素材决策有问题
G4渲染前终审节奏、信息密度、AI 失真与事实准确性渲染是最贵的一步，只在这个点问「要不要渲染」

软闸门（不停顿，但要有自动检查）：TTS 试听校对、把关键帧截图拼成一张联络表（contact sheet）一次性批量过、lint/check 自动门禁。视觉检查一定要批量化——逐帧单看既慢又贵，而且 agent 中途查看一张图片可能作废整个 prompt 缓存。

⚠️ 两个方向都会翻车 闸门太少：完全无人值守在当前模型水平下出不了「满意」的视频。闸门太密：每次停顿都重置上下文，agent 被拖垮，人也被评审淹没。G1–G4 是权衡后的谷底，不是信仰——这条结论有保质期，随模型能力变化，值得每半年重估一次。

6.3常见坑清单（按踩中频率排序）

点击展开每条坑的解法。前两条都与「顺序」有关——这正是第 5 章「先锁口播栏、音频先行」要拆掉的。

#01先做画面后配音（新手第一大坑）
音画错位，截断语音或加速播放都毁观感；语音时长不可压缩，预估必然有误差。
解法：音频先行——TTS 先出真实时长，画面时长反向适配（第 5 章返工模拟器）。
#02没过 G2 就开工：改一句文案，下游全废
口播栏没锁定就做 MG 动画 / 字幕 / 配乐，上游一改全部重做。
解法：口播栏设 G2 硬闸门；定稿前下游只许做不依赖时长与文案的工作。
#03跳过调研直接让 AI 自由发挥
没有调研报告 / 定稿文章当地基，脚本事实没出处，写着写着立场漂移。
解法：流程最上游是内容来源——脚本从调研结果里长出来，不是从一句主题里编出来。
#04AI 视频跨镜头一致性漂移（角色换脸、风格漂移）
先生成一致性关键帧图，再图生视频（I2V）；固定参考图/种子，建角色资产库。同一问题两次纯文本调参无效就换参考锚点，不要盲试第三次。
#05BGM 压人声
观众能容忍画面平庸，不能容忍听不清。
解法：混音做人声避让（ducking）+ 音量标准化；必做人声隔离/增强。
#06AI 编造数据 / 事实
AI 生成的图表数字、「看起来像」的 UI 截图是事实性大坑。
解法：事实核查是独立工序；涉产品/数据的镜头必须回源验证，G4 终审重点盯。
#07TTS 翻车：多音字、数字读法、英文混排
「行长」读成 háng 长、「2026」读法混乱。
解法：TTS 后必须试听校对，这是软闸门里最便宜的一道。
#08字幕晚做
字幕依赖上游词级时间戳，转录质量决定字幕质量。
解法：转录在 TTS 环节同步预留（第 5 章）；ASR 专有名词人工过一遍。
#09生成成本失控
视频生成按次/按秒计费，重试是主成本。
解法：先 draft 质量后 high 质量；同 prompt 缓存不重跑；设预算护栏；无依赖任务并发、有依赖的同序列镜头一次只提交一个。
#10agent 过度工程
让 agent 自由发挥，常把简单动效做复杂。
解法：给它受控的组件库 / 设计规范（frame.md / design.md）与明确的视觉参考。
✓ 本章小结 闸门是权衡不是信仰：设在「下游返工成本 > 评审成本」处，推荐 G1 定位 / G2 口播栏定稿 / G3 画面栏草图 / G4 渲染前终审四个硬闸门 + 不停顿的软闸门（TTS 试听、联络表拼图批量过、lint/check）。坑清单前两名都是顺序问题——第 5 章的工作流能直接拆掉。下一章把流程和闸门串成你下次做视频可以直接照喊的渐进式操作法。
